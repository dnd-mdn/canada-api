# Security policy

## Reporting a vulnerability

We support responsible vulnerability disclosure. If you've found a vulnerability, we would
like to know so we can fix it. Report a vulnerability through GitHub's private vulnerability
reporting:
[Report a vulnerability](https://github.com/dnd-mdn/canada-api/security/advisories/new).
You can submit reports anonymously. Please do not open a public issue for security reports.

---

# Politique de sécurité

## Signaler une vulnérabilité

Nous appuyons la divulgation responsable des vulnérabilités. Si vous avez repéré une
vulnérabilité, nous aimerions le savoir afin de la corriger. Signalez une vulnérabilité au
moyen de la fonctionnalité de signalement privé de vulnérabilité de GitHub :
[Signaler une vulnérabilité](https://github.com/dnd-mdn/canada-api/security/advisories/new).
Vous pouvez également signaler un problème de manière anonyme. Veuillez ne pas ouvrir d'issue
publique pour signaler une vulnérabilité.
